Sahil Razza Portfolio

1. Unzip the folder.
2. Double-click index.html to open it in Chrome, Edge or Firefox.
   (Internet is needed once for the fonts and the 3D library.)

To edit: text in index.html and script.js, colours at the top of style.css (:root), photos in the assets folder (keep the names photo1.jpg to photo5.jpg).

To put it online for free: upload this folder to Netlify Drop (app.netlify.com/drop), GitHub Pages or Vercel.
